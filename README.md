# Curricularizacão 2026 Atualizado
## Sobre o Projeto
Este é um projeto de curricularização com o propósito de ser um jogo didático infantil de 15 questões lúdicas para ensinar as crianças em periodo de pré-alfabetização sobre a cultura de Brusque. Este projeto foi planejado para que tanto o sua protipação e desenvolvimento fossem feito drante o periodo de 2 semanas. 
## Objetivos
-  Ter 15 questões
-  3 Dificuldades
-  3 tipos de questão
-  - verdadeiro ou falso
